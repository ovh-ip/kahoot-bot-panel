🤖 Kahoot Bot — пульт

Настрой ботов (PIN, ники, количество) → получи готовый скрипт → запусти на странице kahoot.it

Как это работает: браузер блокирует запросы к Kahoot с чужих сайтов, поэтому сам скрипт выполняется на странице kahoot.it (через Tampermonkey или вставку в консоль). Этот сайт только собирает скрипт под твои настройки.

3. Ответы

4. Готовый скрипт

Нажми «Собрать скрипт».

5. Запуск

  1. Вариант А (удобно): установи расширение Tampermonkey → нажми «.user.js» выше → откроется установка → «Установить». Затем открой kahoot.it — боты заведутся сами с твоими настройками.
  2. Вариант Б: открой kahoot.it в браузере → нажми Ctrl+Shift+J (консоль) → вставь скрипт из поля выше → Enter.
  3. На странице появится фиолетовая панель: статусы ботов, лог, очки, ввод 2FA, кнопка Stop.
  4. Боты сами зайдут в лобби по PIN, дождутся старта и будут отвечать правильно. Для максимума очков ставь маленькую задержку.
⚠️ Используй только в своих/учебных играх или с разрешения хоста. Зафлуживание чужих игр — нарушение правил Kahoot, ботов могут кикнуть.
